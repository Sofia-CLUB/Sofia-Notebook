SOFIA NOTEBOOK PRO v34 — нові інструменти

ЩО ДОДАНО:
1) 🎡 Колесо фортуни
2) 🃏 Навчальні картки (ручні та через Sofia AI / Groq)
3) ✅ Генератор тестів через Sofia AI / Groq
4) ☷ Списки: нумеровані, марковані, чеклісти, літерні, римські
5) 🌐 Перекладач слова, тексту або виділеного фрагмента через Sofia AI / Groq
6) 🖼 Генерація зображень через окремий endpoint /api/image

ЯК ВСТАНОВИТИ:
- Замініть index.html на файл з цього архіву.
- Додайте у корінь репозиторію:
  teacher-tools-v32.js
  teacher-tools-v32.css
- У папку api додайте image.js
- script.js, style.css, controls-v30.js та інші поточні файли НЕ видаляйте.

ВАЖЛИВО ПРО ЗОБРАЖЕННЯ:
Groq дає текстові відповіді, але сам не генерує зображення.
Для /api/image потрібна окрема змінна Vercel:
POLLINATIONS_KEY
Ключ створюється у Pollinations (enter.pollinations.ai).


ПЕРЕКЛАДАЧ:
- У верхній панелі з'являється кнопка «🌐 Перекладач».
- Можна ввести слово/текст вручну.
- Можна виділити слово або фрагмент у текстовому об'єкті зошита і натиснути «Взяти виділене».
- Переклад працює через уже підключений GROQ_API_KEY, додатковий ключ не потрібен.
- Є кнопки «Вставити переклад на дошку», «Замінити виділене» та «Копіювати».


НОВЕ У v33:
- У вкладці «✅ Тест» після генерації з'являється активна кнопка
  «📄 Вставити тест на сторінку».
- Тест вставляється без правильних відповідей як редагований текстовий блок:
  питання + варіанти А/Б/В/Г.
- Після вставлення блок можна переміщувати, масштабувати та редагувати на дошці.


НОВЕ У v34 — НАЛАШТУВАННЯ ПАНЕЛІ
- У верхній частині з'являється кнопка «⚙ Панель».
- Можна самостійно змінювати порядок кнопок перетягуванням.
- Можна приховувати непотрібні кнопки.
- Окремо налаштовуються:
  1) Верхня панель;
  2) Інструменти над сторінкою;
  3) Ліва вертикальна панель.
- Є «Показати всі» та «Стандартний порядок».
- Налаштування автоматично зберігаються у браузері на конкретному пристрої.
